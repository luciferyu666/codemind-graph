## 新增重點

- 這版主要補強「2026 新手 AI 開源技術地圖」與公開白皮書表述。
- CodeMind Graph 仍是第一優先，定位維持為 AI coding agent 的 repo knowledge layer。
- DevSec Sentinel 是 defense layer，MCP ToolHub 是 governance layer，QuantAgent Lab 是 90 天後的垂直專業品牌專案。
- v0.1 繼續收斂為 TypeScript-first、deterministic graph query、CLI、read-only MCP server、`CODEMIND.md` repo map。
- MVP CLI 優先順序明確化：`codemind index`、`codemind find`、`codemind map`。
- MCP 應寫成「重要開放標準之一」，不要寫成所有 AI 生態的唯一通行證。
- `/goal` 是 agent harness 的長任務管理能力，不是 MCP 的一部分。
- 建議口訣：`/goal` 決定 Agent 要完成什麼；MCP 決定 Agent 能安全調用什麼；Rubric 決定品質是否達標；Governance 決定能否被企業信任。
- TeamPCP / GitHub VS Code extension 事件與 Mini Shai-Hulud / AntV npm 供應鏈事件應分開描述。
- Sonatype 數字應分成 2025 報告與 Q1 2026 指標，不要混在同一句。
- 90 天路線建議：Day 1-30 CodeMind Graph v0.1，Day 31-60 read-only MCP server，Day 61-90 DevSec/Governance，Day 90+ QuantAgent Lab。
