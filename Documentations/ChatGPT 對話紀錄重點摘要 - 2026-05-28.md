## 已納入專案基準的重點

- CodeMind Graph 仍是第一優先開源專案，定位為 AI coding agent 的 local-first code knowledge layer。
- v0.1 應維持 TypeScript-first、CLI-first、Local-first、Read-only MCP-first、Persistent context-first。
- Phase 001 不應整體標記為完成；應以 `docs/RUBRIC.md` 的 Definition of Done 判斷。
- v0.1 parser stack 採 TypeScript Compiler API-first；Tree-sitter、LSP adapter 與 Pyright 放到後續階段評估。
- SQLite + FTS 在 v0.1 僅定位為本地圖譜存儲與全文 symbol lookup，不稱為 semantic search。
- Codex App 是開發 harness；`codemind` CLI 與 read-only MCP server 才是產品介面。
- Codex agents 可讀 `docs/SESSION_STATE.md` 接續工程工作；MCP server 不應預設暴露工程 session notes。
- v0.1 MCP tools 必須 read-only，不提供 edit、shell、install、delete、git push 等能力。
- 新增 `docs/RUBRIC.md` 作為 v0.1 quality gate。
